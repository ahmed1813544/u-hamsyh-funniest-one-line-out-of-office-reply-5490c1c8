## What it does

`main.py` writes a single out-of-office email auto-reply, one line long, to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The line:

> I've left the office to pursue my dream of not answering emails. It's going brilliantly — I'll reply when I wake up.

## Run it

```sh
python3 main.py
```

Python standard library only — no third-party dependencies.
